Home Wi-Fi Troubleshooting

A practical checklist for slow speeds, dead zones, dropouts and devices that will not connect.

Identify the fault

Test the same website on another device. If only one device fails, check that device's Wi-Fi and software settings. If every device fails, check the modem/router connection and your internet provider's outage information. Try an Ethernet connection where practical to separate internet faults from Wi-Fi problems.

Improve router placement

Position the router in an open, elevated, central location rather than inside cabinets or behind metal objects. Walls, large appliances and nearby networks can reduce coverage. Check performance near the router and in the problem room before spending money on new equipment.

Understand 2.4 GHz and 5 GHz

2.4 GHz usually travels farther but can be more congested. 5 GHz is often faster nearby. Some smart-home devices only support 2.4 GHz. Check compatibility and security settings instead of disabling security permanently.

Test one change at a time

Note download/upload speeds and latency close to the router and in the problem area. Change one setting or position, then repeat the measurements. This is more informative than making several changes at once.

Router maintenance

Check the router's firmware and connected-device list. Restart it if necessary, but avoid a factory reset unless you have a backup of its configuration and the details needed to reconnect.

Consider better coverage

A wired access point or appropriately placed mesh node can improve coverage. Where possible, wired backhaul avoids the performance penalty of a weak wireless link between nodes.

When to get help

If Ethernet also fails, contact the internet provider. If problems are intermittent, keep a short log of times and symptoms. For cabling, electrical or security-sensitive changes, seek qualified assistance.
