# Ground Support Crew website

Use the standard Ground Support Crew airplane photo header on every public website page, including product, download and version history pages. Keep the existing airplane image (`1.jpg`), badge logo, Ground Support Crew wordmark and “We Keep You Flying” slogan. Use `resources.html` as the visual reference. The Dictation pages show how to use `assets/gsc-airplane-header.css` with the existing brand styles in `assets/gsc-icons.css`. Check the header and its image on desktop and mobile when adding or updating pages.
